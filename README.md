### 🚀 Was ich baue

Ich entwickle für Handwerk, Beauty, Werkstätten &amp; lokale Dienstleister **individuelle Websites mit einem selbst gebauten CMS** — damit Kunden ihre Seite komplett selbst pflegen, statt für jede Textänderung Stundenlohn an eine Agentur zu zahlen.

- 🧩 **DigiFix-CMS** — ein Backend, viele Sites. Multi-Layout-System, voller Live-Editor, Buchungssystem, DSGVO-konformes Tracking. Läuft auf jedem Linux-Server mit Node.js.
- 🎨 **Websites** — Next.js &amp; Vite, GSAP-Animationen, smooth scroll, voll responsiv, Dark-Theme.
- 🇩🇪 **Hosting in Deutschland** — DSGVO-konform, kein Vendor-Lock-in, Daten jederzeit exportierbar.
- 🛠️ Drumherum: Self-hosted Video-Meetings (Jitsi), Lead-Tooling, Update-Server, internes Dashboard.
